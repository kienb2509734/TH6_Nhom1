TỔNG HỢP CÂU LỆNH MICROSOFT ACCESS – BÀI THỰC HÀNH 06

Ghi chú:
- Các lệnh CREATE TABLE dùng để tạo cấu trúc ba bảng.
- Dữ liệu được nhập từ Excel vào Access bằng External Data > Excel.
- Chạy từng câu SQL riêng trong Access (Create > Query Design > SQL View).
- Các truy vấn Q2a–Q2d tương ứng với bốn yêu cầu truy vấn của bài tập.

============================================================
1. TẠO BẢNG
============================================================

CREATE TABLE SinhVien (
    MSSV TEXT(10) NOT NULL,
    Hoten TEXT(100),
    Lop TEXT(20),
    CONSTRAINT PK_SinhVien PRIMARY KEY (MSSV)
);

CREATE TABLE KetQua (
    MSSV TEXT(10),
    MaMH TEXT(10),
    Diem TEXT(2)
);

CREATE TABLE MonHoc (
    MaMH TEXT(10) NOT NULL,
    TenMH TEXT(100),
    TinChi INTEGER,
    CONSTRAINT PK_MonHoc PRIMARY KEY (MaMH)
);

============================================================
2. CÁC TRUY VẤN BÀI 2
============================================================

Q2a. Liệt kê sinh viên thuộc lớp DI1296A1 hoặc DI1296A2

SELECT MSSV, Hoten, Lop
FROM SinhVien
WHERE Lop IN ('DI1296A1', 'DI1296A2');


Q2b. Liệt kê sinh viên học môn CT178

SELECT S.MSSV, S.Hoten, S.Lop, K.MaMH, K.Diem
FROM SinhVien AS S
INNER JOIN KetQua AS K ON S.MSSV = K.MSSV
WHERE K.MaMH = 'CT178';


Q2c. Liệt kê sinh viên lớp CP1296C1 học môn CT178

SELECT S.MSSV, S.Hoten, S.Lop, K.MaMH, K.Diem
FROM SinhVien AS S
INNER JOIN KetQua AS K ON S.MSSV = K.MSSV
WHERE S.Lop = 'CP1296C1'
  AND K.MaMH = 'CT178';


Q2d. Liệt kê sinh viên lớp CP1296C1 học CT178 và đạt điểm C

SELECT S.MSSV, S.Hoten, S.Lop, K.MaMH, K.Diem
FROM SinhVien AS S
INNER JOIN KetQua AS K ON S.MSSV = K.MSSV
WHERE S.Lop = 'CP1296C1'
  AND K.MaMH = 'CT178'
  AND K.Diem = 'C';
